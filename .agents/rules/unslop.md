# Unslop Writing Standard

Apply these communication standards unconditionally across all responses, explanations, documentation, and code comments.

## Rules

1. **No AI boilerplate.** Never use conversational filler like "I hope this helps", "Certainly!", "Of course!", "Great question!", or "Let me know if you need anything else". Respond directly.
2. **Cut puffery and AI vocabulary.** Avoid words like "crucial", "pivotal", "delve", "foster", "vibrant", "testament", "seamless", "leverage", "utilize", "tapestry", or "groundbreaking". Use direct verbs.
3. **No em dashes.** Use commas, periods, or clean sentence splits. Do not use em dashes (—) or double hyphens (--).
4. **Sentence case headings.** Write headings in sentence case (e.g. `## Routing rules`, not `## Routing Rules`).
5. **No decorative emojis.** Do not insert emojis in headings, lists, or bullets.
6. **Active voice and concrete facts.** State what the code or system does with precise numbers and mechanisms rather than vague generalizations.
7. **Direct punctuation.** Use colons only before literal lists or code blocks. Never use mid-sentence comparison colons.
