# Quirk Dashboard Frontend

- Purpose: Web application containing the public landing page, interactive research insights, legal documentation, and authenticated operator dashboard.
- Ownership: React components, TanStack Router route tree, Tailwind CSS styles, Zustand state stores, and asset assets.

## Local Contracts

1. **Routing & Code Generation**
   - TanStack Router file-based routing lives in `src/routes/`.
   - `src/routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin during dev server runs or build. Never edit `routeTree.gen.ts` manually.
   - Public pages: `/` (Landing), `/insights` (Research & Architecture), `/insights/$slug` (Article detail), `/privacy` (Privacy Policy), `/terms` (Terms of Service).
   - Operator routes live under `src/routes/_authenticated/`.

2. **Design & Brand Tokens**
   - Theme: Clean editorial white (`#FFFFFF`, `#FAFAFA`, `#F7F7F5`) with black typography (`#080808`), neutral muted grays (`#666666`), and fine border lines (`#E5E5E5`).
   - Pure black Quirk logo rendered via `<QuirkLogo lightMode={true} />`.
   - Green (`#22C55E`) is strictly isolated to functional status indicator dots.
   - Fonts: `Satoshi` for headings, `JetBrains Mono` for code/metrics/status pills, `Inter` for body copy.

3. **State Management**
   - Auth & Session state: `src/stores/authStore.ts` (Zustand).
   - Server data queries: Custom hooks in `src/hooks/` and TanStack Query.

## Work Guidance

- Component design follows modern SaaS patterns with Radix UI primitives.
- Code blocks must remain monochromatic (dark slate/near-black background with white/gray text, avoiding neon syntax highlighting).
- Maintain responsiveness across mobile, tablet, and widescreen breakpoints.

## Verification

```bash
# Build production bundle
pnpm --filter quirk-dashboard build

# Run local dev server (default port 3000)
pnpm --filter quirk-dashboard dev
```
